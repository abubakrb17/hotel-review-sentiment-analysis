# Notebooks

This folder contains the analytical development work for the Hotel Review Sentiment Intelligence project.

## Main Notebook

`01_sentiment_analysis.ipynb`

The notebook covers:

- review data exploration
- sentiment label creation
- text cleaning and preprocessing
- TF-IDF feature extraction
- Logistic Regression modeling
- model evaluation
- complaint-theme analysis
- business interpretation

The production Streamlit application is maintained separately from the exploratory notebook.
